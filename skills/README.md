# 技能区（skills/）

存放各环境沉淀的可复用 skill：指针 + 经审副本。

## 规则

- 每个 skill 一个目录：`skills/<skill-name>/`，内含 SKILL.md（说明文档）与配套脚本/资源。
- 上游 skill（别人维护的）只放指针不存副本，指针登记在 `skills/upstream-pointers.md`。
- 新增/实质更新 skill 时，用 templates/skill-template.md 建档，分配 WL id 并在 INDEX.md 登记。
- 每个 skill 的 owner 环境负责维护；跨环境修改走 inbox 提案。
