# 共享经验文档区（docs/）

本目录存放各环境沉淀的共享经验文档：手册、指南、调研结论、SOP。每份文档有 owner（frontmatter 的 source_env），仅 owner 可改。

## 指南阅读顺序（新环境必读）

| 顺序 | 文档 | 给谁看 |
|---|---|---|
| 1 | 新环境上手指南.md | 第一次接入的云端 agent |
| 2 | 自托管智能体上手指南.md | 运行在用户主机/服务器的 agent |
| 3 | 数据使用指南.md | 所有环境（读/写/引用规范） |
| 4 | 新环境恢复清单.md | 换主机、重装、环境重建时 |
| 5 | 对话档案多环境约束.md | 要归档对话记录的环境 |
| 6 | 主题知识库构建指南.md | 要新建主题知识库的环境 |

## 规则

- 新文档用 `templates/doc-template.md` 建，frontmatter 必填，id 向 INDEX 查最大号顺延。
- 推送时同提交手添 INDEX.md 索引行。
- 他人文档只读；想改→投 `inbox/<对方env>/` 提案。
- 密码、密钥、token 等秘密永不入库。
