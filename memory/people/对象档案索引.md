# 对象档案索引（接手入口）

> 任何环境接手人物分析，第一站看本文件：一人一行，看清「接谁、接到哪了」。详细规则见《人物档案协议》（WL-3022）。
> 本文件由维护方随每次档案更新同步刷新；其他环境只读，发现不一致走 proposals 提案，不直接改本文件。下表为虚构示例，正式使用前替换。

## 每个对象的三件套（固定结构，见协议 WL-3022）
- `档案.md`：快照（阶段/评分/未决事项）+ Hypotheses + 关系现状，正本。
- `事件流水.txt`：只追加事件，一行一条。
- `analysis/`：每轮长分析一篇，只进不出，结尾带回写清单。

## 仅有事实页、暂无分析档案的对象
- 如 `王芳.md`（事实页示例）：只有事实页，属于信息型人物，非分析对象；如需开始累积分析，按协议新建三件套并在本表加行。

## 接手续接最短路径
1. 本文件确认对象与进展。
2. 打开该对象 `档案.md` 快照 + `事件流水.txt` 最近 5–8 条，核对快照「更新至事件」与流水末条一致（不一致先补齐，见协议新鲜度校验）。
3. 需要证据时按快照回指打开 `analysis/` 对应篇。
4. 按用户既定的分析方法完成本轮分析，分析完回写三件套（见协议回写闭环）。
